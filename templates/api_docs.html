Lumina REST API v1

Use these endpoints to integrate Lumina with your school portal or dashboards. All endpoints require an API key in the X-API-Key header.

GET /api/v1/leaderboard

Returns top 50 users by best Net WPM.

{"username": "alice", "fullname": "Alice Smith", "level": 5, "best_wpm": 72.5, "best_accuracy": 98.2}

GET /api/v1/users/{id}/stats

Returns aggregate stats and game ratings for a user.

{"total_tests": 45, "avg_net_wpm": 62.3, "avg_accuracy": 97.1, "ratings": {"chess": 1450, "checkers": 1320}}

GET /api/v1/classrooms/{code}/students

Returns students in a classroom with average Net WPM.

[{"id": 3, "username": "bob", "fullname": "Bob Jones", "level": 2, "avg_net_wpm": 55.2}]

POST /api/v1/generate_key

Generate an API key from your dashboard. Include it as X-API-Key in all requests.
